# Contributing to SQL Query Analyzer

Contributions are welcome! Please follow these guidelines:

1. **Fork** the repository and create a feature branch (`feature/description` or `bugfix/issue-number`).
2. **Commit** changes with clear, descriptive messages using [Conventional Commits](https://www.conventionalcommits.org/).
3. **Test**: Ensure all new features or bug fixes have corresponding unit tests.
4. **Style**: Follow the existing coding style defined in `.editorconfig`.
5. **PR**: Submit a pull request with a detailed description of your changes.

### Development Setup
- .NET 10 SDK
- `dotnet restore`
- `dotnet build`
- `dotnet test`

By contributing, you agree that your code will be licensed under the MIT License.
