# StatisticsAggregator

The `StatisticsAggregator` class serves as a central accumulation point for performance metrics and issue analysis results within the `sql-query-analyzer` project. It is designed to ingest individual or batched query analysis outcomes, maintaining running statistical calculations for performance scores, issue severity distributions, optimization opportunities, and query complexity profiles. This type enables the derivation of aggregate insights, such as average performance trends, standard deviations, and percentile rankings, without requiring the retention of raw data sets in memory beyond the calculated summaries.

## API

### Methods

#### `AddResult`
Ingests a single query analysis result into the aggregator, updating all internal counters and statistical running totals immediately.
*   **Parameters**: Accepts the specific result object generated by the analyzer (implementation details depend on the internal result structure).
*   **Returns**: `void`.
*   **Throws**: May throw an `ArgumentNullException` if the provided result is null.

#### `AddResults`
Ingests a collection of query analysis results in a single operation, optimizing the update process for batch scenarios.
*   **Parameters**: Accepts an enumerable collection of result objects.
*   **Returns**: `void`.
*   **Throws**: May throw an `ArgumentNullException` if the collection is null, or `ArgumentException` if any item within the collection is null.

#### `GetAveragePerformanceScore`
Calculates and returns the arithmetic mean of all performance scores added to the aggregator.
*   **Parameters**: None.
*   **Returns**: `double` representing the average score.
*   **Throws**: None. Returns `0.0` if no results have been added.

#### `GetMinPerformanceScore`
Retrieves the lowest performance score recorded among all added results.
*   **Parameters**: None.
*   **Returns**: `double` representing the minimum score.
*   **Throws**: None. Returns `double.MaxValue` if no results have been added.

#### `GetMaxPerformanceScore`
Retrieves the highest performance score recorded among all added results.
*   **Parameters**: None.
*   **Returns**: `double` representing the maximum score.
*   **Throws**: None. Returns `double.MinValue` if no results have been added.

#### `GetPerformanceScoreStdDev`
Computes the standard deviation of the performance scores to indicate the variability or consistency of query performance.
*   **Parameters**: None.
*   **Returns**: `double` representing the standard deviation.
*   **Throws**: None. Returns `0.0` if fewer than two results have been added.

#### `GetPercentile`
Calculates the specific percentile value (e.g., 90th, 95th) for the distribution of performance scores.
*   **Parameters**: `double percentile` (expected range 0.0 to 100.0).
*   **Returns**: `double` representing the score at the requested percentile.
*   **Throws**: May throw `ArgumentOutOfRangeException` if the percentile value is outside the 0.0–100.0 range.

#### `GetIssueCounts`
Aggregates the total number of issues found, grouped by their severity level.
*   **Parameters**: None.
*   **Returns**: `Dictionary<Constants.IssueSeverity, int>` mapping each severity level to its occurrence count.
*   **Throws**: None. Returns an empty dictionary if no issues have been recorded.

#### `GetIssueTypeFrequency`
Aggregates the frequency of specific issue types detected across all analyzed queries.
*   **Parameters**: None.
*   **Returns**: `Dictionary<Constants.IssueType, int>` mapping each issue type to its occurrence count.
*   **Throws**: None. Returns an empty dictionary if no issues have been recorded.

#### `GetMostCommonOptimizations`
Identifies and counts the optimization suggestions generated during analysis, returning them sorted by frequency.
*   **Parameters**: None.
*   **Returns**: `Dictionary<string, int>` where the key is the optimization description and the value is the count.
*   **Throws**: None. Returns an empty dictionary if no optimizations were suggested.

#### `GetTotalOptimizationPotential`
Calculates a cumulative metric representing the total possible performance gain if all suggested optimizations were applied.
*   **Parameters**: None.
*   **Returns**: `double` representing the aggregate potential score.
*   **Throws**: None. Returns `0.0` if no results have been added.

#### `GetComplexityDistribution`
Provides a breakdown of analyzed queries categorized by their computed complexity level.
*   **Parameters**: None.
*   **Returns**: `Dictionary<Constants.QueryComplexity, int>` mapping complexity levels to the count of queries in that category.
*   **Throws**: None. Returns an empty dictionary if no results have been added.

#### `GetSummary`
Generates a comprehensive snapshot object containing all current aggregate statistics.
*   **Parameters**: None.
*   **Returns**: `AggregationSummary` object containing pre-calculated metrics.
*   **Throws**: None.

#### `Clear`
Resets the aggregator to its initial state, removing all previously added results and resetting all statistical counters to zero.
*   **Parameters**: None.
*   **Returns**: `void`.
*   **Throws**: None.

### Properties

#### `TotalQueries`
Gets the total number of individual query results currently stored in the aggregator.
*   **Type**: `int`
*   **Remarks**: Returns `0` immediately after construction or calling `Clear`.

#### `AverageScore`
Gets the current arithmetic mean of performance scores.
*   **Type**: `double`
*   **Remarks**: Equivalent to calling `GetAveragePerformanceScore()`. Returns `0.0` if `TotalQueries` is 0.

#### `MinScore`
Gets the current minimum performance score recorded.
*   **Type**: `double`
*   **Remarks**: Equivalent to calling `GetMinPerformanceScore()`.

#### `MaxScore`
Gets the current maximum performance score recorded.
*   **Type**: `double`
*   **Remarks**: Equivalent to calling `GetMaxPerformanceScore()`.

#### `ScoreStdDev`
Gets the current standard deviation of the performance scores.
*   **Type**: `double`
*   **Remarks**: Equivalent to calling `GetPerformanceScoreStdDev()`.

#### `TotalIssuesFound`
Gets the cumulative count of all issues detected across all added results.
*   **Type**: `int`
*   **Remarks**: Sum of all values in the dictionary returned by `GetIssueCounts()`.

## Usage

### Example 1: Batch Processing and Summary Generation
This example demonstrates initializing the aggregator, processing a batch of analysis results, and retrieving a high-level summary.

```csharp
using SqlQueryAnalyzer;
using System.Collections.Generic;

public void AnalyzeBatch(IEnumerable<QueryAnalysisResult> results)
{
    var aggregator = new StatisticsAggregator();
    
    // Ingest the entire batch
    aggregator.AddResults(results);
    
    // Retrieve a comprehensive summary object
    AggregationSummary summary = aggregator.GetSummary();
    
    Console.WriteLine($"Processed: {aggregator.TotalQueries} queries");
    Console.WriteLine($"Average Score: {summary.AveragePerformance:F2}");
    Console.WriteLine($"Total Issues: {aggregator.TotalIssuesFound}");
    
    // Inspect severity distribution
    var severityCounts = aggregator.GetIssueCounts();
    if (severityCounts.ContainsKey(Constants.IssueSeverity.Critical))
    {
        Console.WriteLine($"Critical Issues Found: {severityCounts[Constants.IssueSeverity.Critical]}");
    }
}
```

### Example 2: Incremental Analysis with Percentile Calculation
This example shows adding results incrementally (e.g., in a streaming scenario) and calculating specific percentile thresholds for performance reporting.

```csharp
using SqlQueryAnalyzer;

public void StreamAnalysis()
{
    var aggregator = new StatisticsAggregator();
    
    // Simulate streaming results one by one
    for (int i = 0; i < 100; i++)
    {
        var result = QueryEngine.Analyze(GetNextQuery());
        aggregator.AddResult(result);
    }
    
    // Calculate 95th percentile performance threshold
    double p95Score = aggregator.GetPercentile(95.0);
    double stdDev = aggregator.GetPerformanceScoreStdDev();
    
    Console.WriteLine($"95th Percentile Score: {p95Score}");
    Console.WriteLine($"Performance Variability (StdDev): {stdDev}");
    
    // Review most common optimization opportunities
    var optimizations = aggregator.GetMostCommonOptimizations();
    foreach (var opt in optimizations)
    {
        Console.WriteLine($"{opt.Key}: Suggested {opt.Value} times");
    }
    
    // Reset for next batch if needed
    aggregator.Clear();
}
```

## Notes

*   **Thread Safety**: The `StatisticsAggregator` is not thread-safe. Concurrent calls to `AddResult`, `AddResults`, or `Clear` from multiple threads without external synchronization (e.g., `lock` statement) may result in corrupted internal state or inaccurate statistical calculations.
*   **Empty State Behavior**: Accessing statistical properties (e.g., `AverageScore`, `MinScore`) or calling getter methods on an empty aggregator (where `TotalQueries` is 0) will not throw exceptions but will return default neutral values (typically `0.0` for scores and counts, or extreme double values for Min/Max depending on implementation logic).
*   **Memory Usage**: The class is designed to maintain running statistics; however, depending on the internal implementation of `GetMostCommonOptimizations` or `GetIssueTypeFrequency`, distinct string keys or enum values are retained. Calling `Clear()` is recommended between distinct analysis sessions to prevent unbounded memory growth in long-running processes.
*   **Percentile Precision**: The `GetPercentile` method relies on the distribution of currently stored scores. If the number of added queries is very low (e.g., less than 10), percentile calculations may be statistically insignificant or approximate.
