# QueryCacheKeyGenerator

Utility class responsible for generating consistent, deterministic cache keys for SQL queries, results, metadata, and batches. It ensures that logically equivalent queries produce the same cache key while distinguishing between different types of cache entries.

## API

### `GenerateQueryKey`

Generates a cache key uniquely representing the SQL query text and its parameters.

- **Parameters**
  - `query`: The SQL query string to be cached.
  - `parameters`: Optional collection of parameters used in the query.
- **Return value**
  Returns a string key that uniquely identifies the query and its parameters.
- **Exceptions**
  Throws `ArgumentNullException` if `query` is `null`.

### `GenerateResultKey`

Generates a cache key for storing query execution results.

- **Parameters**
  - `queryKey`: The cache key generated by `GenerateQueryKey`.
- **Return value**
  Returns a string key prefixed to indicate a result cache entry.
- **Exceptions**
  Throws `ArgumentNullException` if `queryKey` is `null`.

### `GenerateMetadataKey`

Generates a cache key for storing query metadata.

- **Parameters**
  - `queryKey`: The cache key generated by `GenerateQueryKey`.
- **Return value**
  Returns a string key prefixed to indicate a metadata cache entry.
- **Exceptions**
  Throws `ArgumentNullException` if `queryKey` is `null`.

### `GenerateBatchKey`

Generates a cache key for a batch of queries.

- **Parameters**
  - `queries`: Collection of SQL query strings to be batched.
  - `parameters`: Optional collection of parameter sets corresponding to each query.
- **Return value**
  Returns a string key representing the entire batch.
- **Exceptions**
  Throws `ArgumentNullException` if `queries` is `null`.

### `IsValidCacheKey`

Determines whether a given string is a valid cache key generated by this generator.

- **Parameters**
  - `key`: The cache key to validate.
- **Return value**
  Returns `true` if the key is valid; otherwise, `false`.

### `ExtractHashFromKey`

Extracts the hash portion from a cache key generated by this generator.

- **Parameters**
  - `key`: The cache key from which to extract the hash.
- **Return value**
  Returns the hash portion as a string if the key is valid; otherwise, `null`.

### `GetKeyType`

Identifies the type of a cache key generated by this generator.

- **Parameters**
  - `key`: The cache key to analyze.
- **Return value**
  Returns a `CacheKeyType` enum value indicating the key type.
- **Exceptions**
  Throws `ArgumentNullException` if `key` is `null`.

## Usage

### Example 1: Caching a parameterized query

```csharp
var generator = new QueryCacheKeyGenerator();
var parameters = new Dictionary<string, object> { ["@id"] = 42 };

// Generate a query key
string query = "SELECT * FROM Users WHERE Id = @id";
string queryKey = generator.GenerateQueryKey(query, parameters);

// Generate a result key
string resultKey = generator.GenerateResultKey(queryKey);

// Use the keys to store/retrieve from cache
```

### Example 2: Validating and extracting from a batch key

```csharp
var generator = new QueryCacheKeyGenerator();
var queries = new[] { "SELECT * FROM Orders", "SELECT * FROM Customers" };

// Generate a batch key
string batchKey = generator.GenerateBatchKey(queries);

// Validate the key
bool isValid = generator.IsValidCacheKey(batchKey); // true

// Extract the hash
string? hash = generator.ExtractHashFromKey(batchKey);
CacheKeyType keyType = generator.GetKeyType(batchKey);
```

## Notes

- **Thread safety**: All methods are thread-safe and may be called concurrently from multiple threads.
- **Key format**: Generated keys are deterministic and include a hash derived from the input content. Changing the input (query text or parameters) produces a different key.
- **Invalid keys**: Methods like `ExtractHashFromKey` and `GetKeyType` return `null` or throw only when the input is explicitly `null`; malformed keys (e.g., empty or manually altered) are treated as invalid rather than causing exceptions.
- **Parameter order**: Parameter order in `GenerateQueryKey` does not affect the resulting key; the generator normalizes parameter order to ensure consistent keys for equivalent queries.
