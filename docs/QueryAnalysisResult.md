# QueryAnalysisResult

The `QueryAnalysisResult` class serves as the immutable container for the output generated by the SQL query analysis pipeline within the `sql-query-analyzer` project. It encapsulates the original query string, a unique identifier for tracking, temporal metadata, and a comprehensive set of analytical findings including complexity metrics, performance scoring, estimated execution times, and detected issues. Additionally, it provides structured recommendations for indexing, the optional execution plan, statistical data, and extensible metadata, offering a unified interface for consuming analysis results in logging, UI display, or further programmatic processing.

## API

### Properties

#### `public string QueryId`
Gets the unique identifier assigned to this specific analysis session. This ID is used to correlate logs, execution plans, and historical data.
*   **Return Value**: A non-null string representing the GUID or unique key.
*   **Throws**: None.

#### `public string Query`
Gets the original SQL query string that was submitted for analysis.
*   **Return Value**: The raw SQL text.
*   **Throws**: None.

#### `public DateTime AnalyzedAt`
Gets the UTC timestamp indicating when the analysis process completed.
*   **Return Value**: A `DateTime` value representing the completion time.
*   **Throws**: None.

#### `public QueryComplexity Complexity`
Gets the calculated complexity rating of the query (e.g., Low, Medium, High, Critical).
*   **Return Value**: An enum value of type `QueryComplexity`.
*   **Throws**: None.

#### `public double PerformanceScore`
Gets the normalized performance score, typically ranging from 0.0 (poor) to 100.0 (optimal).
*   **Return Value**: A `double` representing the score.
*   **Throws**: None.

#### `public TimeSpan EstimatedExecutionTime`
Gets the predicted duration for the query to execute based on current statistics and plan estimation.
*   **Return Value**: A `TimeSpan` object.
*   **Throws**: None.

#### `public List<PerformanceIssue> Issues`
Gets the collection of identified performance bottlenecks, anti-patterns, or potential errors.
*   **Return Value**: A list of `PerformanceIssue` objects. The list may be empty if no issues are found but will not be null.
*   **Throws**: None.

#### `public List<IndexSuggestion> IndexSuggestions`
Gets the list of recommended index creations or modifications to improve query performance.
*   **Return Value**: A list of `IndexSuggestion` objects. The list may be empty but will not be null.
*   **Throws**: None.

#### `public QueryPlan? ExecutionPlan`
Gets the detailed execution plan generated by the database engine or the analyzer's simulation.
*   **Return Value**: A `QueryPlan` object if available; otherwise, `null`.
*   **Throws**: None.

#### `public QueryStatistics Statistics`
Gets the statistical data associated with the query analysis, such as row estimates, I/O costs, and CPU usage estimates.
*   **Return Value**: A `QueryStatistics` object.
*   **Throws**: None.

#### `public Dictionary<string, object> Metadata`
Gets a dictionary containing extensible key-value pairs for additional context, tags, or analyzer-specific data.
*   **Return Value**: A dictionary mapping string keys to object values. The dictionary is initialized and not null.
*   **Throws**: None.

### Methods

#### `public string GetSummary`
Generates a human-readable textual summary of the analysis results, highlighting the complexity, score, and critical issues.
*   **Parameters**: None.
*   **Return Value**: A formatted `string` summarizing the key findings.
*   **Throws**: None.

#### `public Dictionary<string, object> ToJsonDictionary`
Converts the entire analysis result into a flat or nested dictionary structure suitable for serialization to JSON.
*   **Parameters**: None.
*   **Return Value**: A `Dictionary<string, object>` representing the serializable state of the object.
*   **Throws**: None.

## Usage

### Example 1: Basic Analysis Inspection
The following example demonstrates retrieving an analysis result and inspecting critical metrics and issues.

```csharp
// Assume 'analyzer' is an initialized instance of the query analyzer
var result = await analyzer.AnalyzeAsync("SELECT * FROM Orders WHERE OrderDate > '2023-01-01'");

// Check performance score and complexity
if (result.PerformanceScore < 70.0 || result.Complexity == QueryComplexity.High)
{
    Console.WriteLine($"Warning: Query {result.QueryId} has suboptimal performance.");
    Console.WriteLine($"Estimated Time: {result.EstimatedExecutionTime.TotalMilliseconds}ms");
    
    // Iterate over detected issues
    foreach (var issue in result.Issues)
    {
        Console.WriteLine($"- Issue: {issue.Description} (Severity: {issue.Severity})");
    }
}
else
{
    Console.WriteLine($"Query {result.QueryId} analysis completed successfully at {result.AnalyzedAt}.");
}
```

### Example 2: Serialization and Recommendation Processing
This example shows how to convert the result to a dictionary for logging and process index suggestions.

```csharp
var result = await analyzer.AnalyzeAsync(complexSqlQuery);

// Convert to dictionary for external logging or API response
var payload = result.ToJsonDictionary();
payload["AnalyzedBy"] = "SqlQueryAnalyzer_v2";
payload["Environment"] = "Production";

// Process index suggestions
if (result.IndexSuggestions.Count > 0)
{
    Console.WriteLine($"Found {result.IndexSuggestions.Count} index recommendations:");
    foreach (var suggestion in result.IndexSuggestions)
    {
        Console.WriteLine($"CREATE INDEX {suggestion.IndexName} ON {suggestion.TableName} ({string.Join(", ", suggestion.Columns)});");
    }
}

// Access optional execution plan
if (result.ExecutionPlan != null)
{
    var planXml = result.ExecutionPlan.ToXml();
    // Save planXml to disk or display in UI
}
```

## Notes

*   **Nullability**: The `ExecutionPlan` property is nullable (`QueryPlan?`). Consumers must check for `null` before accessing members of the execution plan, as certain analytical modes or failed compilations may not produce a plan. All collection properties (`Issues`, `IndexSuggestions`, `Metadata`) are guaranteed to be initialized and non-null, though they may be empty.
*   **Immutability**: While the collections themselves are mutable lists/dictionaries, the `QueryAnalysisResult` instance is designed to represent a snapshot in time. Modifying the contents of `Issues`, `IndexSuggestions`, or `Metadata` after the object is returned by the analyzer may lead to inconsistent state if the object is shared across threads.
*   **Thread Safety**: The `QueryAnalysisResult` class is safe for concurrent read access from multiple threads provided that the contained collections (`List<T>`, `Dictionary<K,V>`) are not modified during iteration. If the `Metadata` or suggestion lists need to be modified, external synchronization or a defensive copy should be used.
*   **Time Zones**: The `AnalyzedAt` property always returns a `DateTime` in UTC. Consumers responsible for UI display should convert this value to the local time zone as needed.
*   **Serialization**: The `ToJsonDictionary` method handles the conversion of complex types (like `TimeSpan` and `DateTime`) into JSON-compatible formats. Direct serialization of the class instance via standard serializers may require custom converters depending on the runtime environment, whereas the dictionary output is immediately serializable.
