# ExportService
The `ExportService` provides a centralized way to export query results or arbitrary data objects to various file formats. It supports registering custom formatters, exporting single or multiple batches, generating optional reports, and applying compression with optional password protection.

## API
### RegisterFormatter
**Purpose:** Associates a custom formatter implementation with a specific format identifier so that the service can use it during export operations.  
**Parameters:**  
- `format` – The name of the format (e.g., `"csv"`, `"xlsx"`).  
- `formatter` – An object implementing the formatter contract used to serialize data.  
**Return value:** None (`void`).  
**Exceptions:**  
- `ArgumentNullException` if `format` or `formatter` is `null`.  
- `ArgumentException` if `format` is empty or whitespace.  

### ExportAsync
**Purpose:** Exports a single data object to the specified format and writes the result to a file.  
**Parameters:**  
- `data` – The object to export.  
- `format` – The target format; must be registered or natively supported.  
- `filePath` – Full path where the exported file will be written.  
**Return value:** A `Task` that completes when the export operation finishes.  
**Exceptions:**  
- `ArgumentNullException` if any parameter is `null`.  
- `NotSupportedException` if ` if the format is not format is supported.  
- `IOException` if the file cannot be created or written.  
- `InvalidOperationException` if no formatter is registered for the format.  

### ExportBatchAsync
**Purpose:** Exports a collection of data objects as a single batch to the specified format.  
**Parameters:**  
- `data` – Enumerable of objects to export.  
- `format` – Target format; must be registered or natively supported.  
- `filePath` – Destination file path.  
**Return value:** A `Task` that completes when the batch export finishes.  
**Exceptions:**  
- `ArgumentNullException` if `data`, `format`, or `filePath` is `null`.  
- `NotSupportedException` if the format is unsupported.  
- `IOException` on file‑system errors.  
- `InvalidOperationException` if no formatter exists for the format.  

### ExportMultipleFormatsAsync
**Purpose:** Exports the same data object to several formats in one call, producing separate files for each format.  
**Parameters:**  
- `data` – The object to export.  
- `formats` – Collection of format identifiers to export to.  
- `baseFilePath` – Base path without extension; each format will append its appropriate extension.  
**Return value:** A `Task` that completes when all exports finish.  
**Exceptions:**  
- `ArgumentNullException` if any parameter is `null`.  
- `NotSupportedException` if any format in `formats` is unsupported.  
- `IOException` if any output file cannot be created.  
- `InvalidOperationException` if a formatter is missing for a requested format.  

### ExportWithReportAsync
**Purpose:** Exports data to a file and optionally generates an accompanying report file (e.g., a summary or log).  
**Parameters:**  
- `data` – The object to export.  
- `format` – Target format for the main export.  
- `filePath` – Destination path for the main export file.  
- `reportOptions` – Configuration controlling report generation (e.g., include timestamps, summary statistics).  
**Return value:** A `Task` that completes when both the export and report are finished.  
**Exceptions:**  
- `ArgumentNullException` if `data`, `format`, `filePath`, or `reportOptions` is `null`.  
- `NotSupportedException` if the format is unsupported.  
- `IOException` on file‑system failures.  
- `InvalidOperationException` if no formatter is registered for the format.  

### GetSupportedFormats
**Purpose:** Returns a list of all format identifiers that the service can handle (including built‑in and registered formatters).  
**Parameters:** None.  
**Return value:** `List<string>` containing format names.  
**Exceptions:** None.  

### IsFormatSupported
**Purpose:** Checks whether a given format identifier is supported by the service.  
**Parameters:**  
- `format` – The format identifier to test.  
**Return value:** `true` if the format is supported; otherwise `false`.  
**Exceptions:**  
- `ArgumentNullException` if `format` is `null`.  

### Formats
**Purpose:** Gets the collection of format identifiers currently registered with the service (read‑only view).  
**Return value:** `List<string>` of format names.  
**Exceptions:** None.  

### OutputDirectory
**Purpose:** Gets or sets the default directory where exported files are placed when a relative path is supplied.  
**Return value:** `string` representing the directory path.  
**Exceptions:**  
- `ArgumentException` if set to an invalid path.  

### IncludeReport
**Purpose:** Gets or sets a flag indicating whether an accompanying report should be generated by export methods that support it.  
**Return value:** `bool`; `true` to include a report, `false` otherwise.  
**Exceptions:** None.  

### Compress
**Purpose:** Gets or sets a flag indicating whether the exported file should be compressed (e.g., ZIP).  
**Return value:** `bool`; `true` enables compression.  
**Exceptions:** None.  

### CompressionPassword
**Purpose:** Gets or sets the optional password used to protect compressed archives. If `null`, no password is applied.  
**Return value:** `string?` – the password or `null`.  
**Exceptions:** None.  

## Usage
```csharp
using System.IO;
using System.Threading.Tasks;
using SqlQueryAnalyzer.Export;

// Assume a simple POCO representing query results
public class SalesRecord { public int Id { get; set; } public decimal Amount { get; set; } }

public async Task ExportSingleFileAsync()
{
    var service = new ExportService();
    // Register a CSV formatter (could be built‑in or custom)
    service.RegisterFormatter("csv", new CsvFormatter());

    var data = new SalesRecord { Id = 1, Amount = 123.45m };
    service.OutputDirectory = Path.Combine(Environment.CurrentDirectory, "exports, file to the file will be written to the default directory.

    await service.ExportAsync(data, "csv", "sales.csv");
}
```

```csharp
using System.Collections.Generic;
using System.IO;
using System.Threading.Tasks;
using SqlQueryAnalyzer.Export;

public async Task ExportBatchWithCompressionAsync()
{
    var service = new ExportService();
    service.RegisterFormatter("xlsx", new ExcelFormatter());
    service.IncludeReport = true;
    service.Compress = true;
    service.CompressionPassword = "s3cr3t!";
    service.OutputDirectory = Path.GetTempPath();

    var records = new List<SalesRecord>
    {
        new SalesRecord { Id = 1, Amount = 100 },
        new SalesRecord { Id = 2, Amount = 200 }
    };

    await service.ExportBatchAsync(records, "xlsx", "sales_report");
    // Produces sales_report.xlsx (encrypted ZIP) and an optional report file.
}
```

## Notes
- **Null arguments:** All export‑related methods throw `ArgumentNullException` for any `null` parameter; callers should validate inputs before invoking the service.  
- **Unsupported formats:** Attempting to export with a format that has not been registered or is not natively supported results in `NotSupportedException`. Use `IsSupported formats can be queried via `GetSupportedFormats` or `IsFormatSupported`.  
- **Formatter registration:** The service is safe for concurrent export calls once formatters are registered. However, registering or deregistering formatters while an export operation is in progress may lead to `InvalidOperationException` or undefined behavior; registration should be completed before starting any export tasks.  
- **Compression and password:** When `Compress` is set to `true`, the output file is wrapped in a ZIP archive. If `CompressionPassword` is non‑`null`, the archive is encrypted with that password; attempting to decrypt without the correct password will fail downstream.  
- **Report generation:** The `IncludeReport` flag only affects methods that have a report parameter (`ExportWithReportAsync`). Setting it to `true` has no effect on other export overloads.  
- **Directory handling:** If a relative file path is supplied, the service resolves it against `OutputDirectory`. An invalid directory throws `ArgumentException`.  
- **Thread‑safety:** The service’s internal state (format collection, options) is safe for reads after initialization. Mutating state (e.g., changing `OutputDirectory` or toggling `Compress`) should be done with external synchronization if multiple threads may modify the service concurrently.  
- **Exceptions from formatters:** Any exception thrown by a registered formatter during serialization is propagated outward; callers may wish to catch formatter‑specific exceptions as needed.
