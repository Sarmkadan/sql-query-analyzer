# QueryPlan

Represents the parsed execution plan of a SQL query captured by the analyzer. It aggregates metadata about the plan (such as identifiers, timestamps, and cost estimates) and provides convenient access to the hierarchical plan nodes and derived collections like table accesses and joins.

## API

### PlanId
- **Purpose:** Unique identifier for the captured plan, typically a GUID or hash generated at capture time.
- **Type:** `string`
- **Remarks:** Read‑only; never returns `null` after the plan has been initialized.

### DatabaseName
- **Purpose:** Name of the database against which the query was executed when the plan was captured.
- **Type:** `string`
- **Remarks:** May be `null` if the plan was captured without a database context (e.g., a standalone script).

### CapturedAt
- **Purpose:** Timestamp indicating when the plan was captured from the server.
- **Type:** `DateTime`
- **Remarks:** Stored as UTC; reflects the exact moment the analyzer recorded the plan.

### IsEstimated
- **Purpose:** Indicates whether the plan is an estimated plan (generated by the optimizer) or an actual plan (collected at runtime).
- **Type:** `bool`
- **Remarks:** `true` for estimated plans, `false` for actual plans.

### Format
- **Purpose:** Enumeration describing the serialization format of the raw plan (e.g., XML, JSON, Graphical).
- **Type:** `PlanFormat`
- **Remarks:** Determines how the raw plan string should be interpreted; never `null`.

### RootNode
- **Purpose:** The top‑most node of the plan tree; entry point for traversing the hierarchical representation of operators.
- **Type:** `PlanNode?`
- **Remarks:** Can be `null` if the plan could not be parsed or is empty; after successful initialization it references a valid node.

### TotalEstimatedCost
- **Purpose:** Aggregated estimated cost of the entire plan, as reported by the optimizer.
- **Type:** `double`
- **Remarks:** Unitless cost metric used internally by the query optimizer; zero if not available.

### TotalEstimatedIoCost
- **Purpose:** Estimated I/O cost component of the total estimated cost.
- **Type:** `double`
- **Remarks:** Represents the predicted cost of data reads/writes; zero if unavailable.

### TotalEstimatedCpuCost
- **Purpose:** Estimated CPU cost component of the total estimated cost.
- **Type:** `double`
- **Remarks:** Represents the predicted cost of CPU processing; zero if unavailable.

### TotalEstimatedRows
- **Purpose:** Estimated number of rows that the plan will process.
- **Type:** `int`
- **Remarks:** May be zero for plans that return no rows (e.g., DDL statements).

### TotalElapsedTime
- **Purpose:** Actual wall‑clock time elapsed during query execution (for actual plans) or estimated elapsed time (for estimated plans).
- **Type:** `TimeSpan`
- **Remarks:** Zero if timing information was not captured.

### TotalLogicalReads
- **Purpose:** Number of logical reads performed during execution.
- **Type:** `long`
- **Remarks:** Reflects reads from the buffer cache; zero if not measured.

### TotalPhysicalReads
- **Purpose:** Number of physical reads performed during execution.
- **Type:** `long`
- **Remarks:** Reflects reads from disk; zero if not measured.

### AllNodes
- **Purpose:** Flat collection containing every `PlanNode` in the plan, facilitating LINQ queries or bulk operations.
- **Type:** `List<PlanNode>`
- **Remarks:** Never `null`; empty list if the plan contains no nodes. The list is a snapshot; modifications to the list do not affect the internal tree structure.

### TableAccesses
- **Purpose:** Collection of all `TableAccess` objects representing scans, seeks, or lookups against base tables.
- **Type:** `List<TableAccess>`
- **Remarks:** Never `null`; empty if the plan does not reference any base tables.

### Joins
- **Purpose:** Collection of all `Join` objects representing join operations (e.g., inner join, left outer join) present in the plan.
- **Type:** `List<Join>`
- **Remarks:** Never `null`; empty if the plan contains no joins.

### Initialize
- **Purpose:** Prepares the `QueryPlan` instance for use by parsing the raw plan string, building the node tree, and populating derived collections.
- **Signature:** `public void Initialize()`
- **Parameters:** None.
- **Return Value:** None.
- **Exceptions:**
  - `InvalidOperationException` if `Initialize` is called more than once.
  - `ArgumentNullException` if the underlying raw plan data has not been supplied prior to calling this method.
  - `FormatException` if the raw plan cannot be parsed according to the `Format` property.

### GetExpensiveOperations
- **Purpose:** Returns a list of plan nodes whose estimated cost exceeds a predefined threshold (typically the top 10 % costliest nodes).
- **Signature:** `public List<PlanNode> GetExpensiveOperations()`
- **Parameters:** None.
- **Return Value:** `List<PlanNode>` containing the expensive nodes; empty list if no nodes exceed the threshold.
- **Exceptions:**
  - `InvalidOperationException` if `Initialize` has not been called successfully.

### GetTableScans
- **Purpose:** Retrieves all nodes that represent a full table scan operation.
- **Signature:** `public List<PlanNode> GetTableScans()`
- **Parameters:** None.
- **Return Value:** `List<PlanNode>` of table scan nodes; empty if none exist.
- **Exceptions:**
  - `InvalidOperationException` if `Initialize` has not been called successfully.

### GetIndexOperations
- **Purpose:** Retrieves all nodes that represent index seeks, scans, or lookups.
- **Signature:** `public List<PlanNode> GetIndexOperations()`
- **Parameters:** None.
- **Return Value:** `List<PlanNode>` of index‑related nodes; empty if none exist.
- **Exceptions:**
  - `InvalidOperationException` if `Initialize` has not been called successfully.

## Usage

```csharp
// Example 1: Loading and inspecting a captured actual plan
var plan = new QueryPlan
{
    PlanId = Guid.NewGuid().ToString(),
    DatabaseName = "SalesDB",
    CapturedAt = DateTime.UtcNow,
    IsEstimated = false,
    Format = PlanFormat.Xml,
    // Raw plan string would be set elsewhere before initialization
};
plan.Initialize(); // populates RootNode, AllNodes, etc.

Console.WriteLine($"Plan captured at {plan.CapturedAt:u}");
Console.WriteLine($"Total estimated cost: {plan.TotalEstimatedCost}");
Console.WriteLine($"Rows processed: {plan.TotalEstimatedRows}");

var scans = plan.GetTableScans();
if (scans.Any())
{
    Console.WriteLine($"Found {scans.Count} table scan(s).");
}
else
{
    Console.WriteLine("No table scans detected.");
}
```

```csharp
// Example 2: Analyzing an estimated plan for expensive operations
var estimatedPlan = new QueryPlan
{
    PlanId = "est-001",
    DatabaseName = null, // ad‑hoc batch
    CapturedAt = DateTime.UtcNow.AddMinutes(-5),
    IsEstimated = true,
    Format = PlanFormat.Json,
    // raw JSON plan supplied via constructor or property elsewhere
};
estimatedPlan.Initialize();

var expensive = estimatedPlan.GetExpensiveOperations();
foreach (var node in expensive)
{
    Console.WriteLine($"Expensive operation: {node.OperatorType} (cost {node.EstimatedCost})");
}

// Access join information directly from the aggregated collection
foreach (var join in estimatedPlan.Joins)
{
    Console.WriteLine($"Join: {join.JoinType} on {join.LeftTable} ↔ {join.RightTable}");
}
```

## Notes

- **Initialization requirement:** All members that depend on the parsed plan tree (`RootNode`, `AllNodes`, `TableAccesses`, `Joins`, and the three `Get*` methods) are only valid after a successful call to `Initialize`. Accessing them before initialization may result in `InvalidOperationException` or return default/empty values.
- **Nullability:** `RootNode` can be `null` if the plan fails to parse or is intentionally empty. All collection properties (`AllNodes`, `TableAccesses`, `Joins`) are guaranteed to be non‑null but may be empty.
- **Thread safety:** The `QueryPlan` type is **not** thread‑safe. Concurrent calls to `Initialize` or to the query methods from multiple threads without external synchronization can lead to undefined behavior, including corrupted internal state or exceptions. It is safe to read immutable properties after initialization from multiple threads, but any mutation (e.g., re‑calling `Initialize`) must be guarded.
- **Cost semantics:** The cost‑related properties (`TotalEstimatedCost`, `TotalEstimatedIoCost`, `TotalEstimatedCpuCost`) reflect the optimizer’s estimates and may be zero when the plan does not contain cost information (e.g., certain utility commands). They should not be treated as absolute performance metrics.
- **Timing:** `TotalElapsedTime` captures wall‑clock time only for actual plans; for estimated plans it represents the optimizer’s predicted elapsed time and may not correspond to real execution duration.
- **Reads:** Logical and physical read counters are populated only when the server provides them; otherwise they default to zero. Differences between logical and physical reads can be used to infer cache effectiveness.
